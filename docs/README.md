# Documentation

This folder contains feature roadmaps and design notes for SavvyCAN development.
For end-user instructions, see the [application help index](../help/README.md).

## Feature roadmaps

- [FlexRay reverse engineering](flexray-re-roadmap.md) — parser, capture metadata,
  and reverse-engineering workflow improvements.
- [GitHub repositories](github-repos-roadmap.md) — loading and saving logs and
  DBC files through GitHub.
- [Log notes](log-notes-roadmap.md) — setup details, scenarios, and markers
  associated with log files.
- [OBD-II poller](obd2-roadmap.md) — polling vehicle parameters alongside
  captured bus traffic.

These documents describe feature-specific plans and implementation history.
Check each document's status and dates before treating a roadmap entry as a
current project commitment.
